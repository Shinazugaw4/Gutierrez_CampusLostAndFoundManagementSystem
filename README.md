# Campus Lost and Found Management System

## Description
The Campus Lost and Found Management System is a Django-based prototype application developed for the Integrated System Development Project (ISDP). The system allows students to report lost items, view reported items, and submit claim requests through a simple web interface and backend API services.

---

## Features
- Report Lost Item
- View Reported Items
- Claim Lost Item
- Automatic Removal of Claimed Items
- Backend API Integration
- Selenium IDE UI Testing
- Postman API Testing

## Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/Shinazugaw4/Gutierrez_CampusLostAndFoundManagementSystem
```

### 2. Open Project Folder

```bash
cd Gutierrez_CampusLostAndFoundManagementSystem
```

### 3. Install Django

```bash
pip install django
```

### 4. Run the Server

```bash
py manage.py runserver
```

### 5. Open in Browser

```text
http://127.0.0.1:8000
```

---

## API Endpoints

### View Items
```text
GET /api/items
```

### Report Item
```text
POST /api/items/report
```

### Claim Item
```text
POST /api/items/claim
```
