# Campus Lost and Found Management System

## Description
The Campus Lost and Found Management System is a Django-based prototype application that allows students to report, view, and claim lost items inside the campus.

---

## Features
- Report Lost Item
- View Lost Items
- Claim Item
- API Integration
- Selenium IDE Testing
- Postman API Testing

---

## Technologies Used
- Django
- SQLite
- HTML
- CSS
- Postman
- Selenium IDE
- Visual Studio Code
